# Estado vivo da fila — app "Onde eu voto?" (v3)

Este branch órfão guarda só `fila.json`: quão cheia está cada zona (A/B/C) do Ring 3 e se o
status de fila está ativado para o eleitor. É escrito pela página da equipe e pela do
administrador (API do GitHub, token restrito a este repositório) e lido pela página do eleitor
via `raw.githubusercontent.com`. Não contém dado pessoal. Não editar à mão durante a votação.
