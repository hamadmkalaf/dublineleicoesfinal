## O que a v3 acrescenta

1. **Nº do eleitor no caderno** (equipe): posição alfabética na seção; acima de 200, menos 200
   (256º → 56). Calculado no build (`numera_caderno`), campos `p`/`c` no pacote da equipe.
2. **Tempo estimado de espera**: a equipe informa uma porcentagem por zona A/B/C no painel "Fila no
   Ring 3" e publica; o eleitor vê "cerca de N min" abaixo da nota da preferencial, se o admin ativou.
   Modelo: `pct × 706 / (urnas × 60/60 s) + 3 min`, arredondado a 5 min (parâmetros em `config.json → fila`).
3. **Área do administrador** (`admin/`): senha só como hash PBKDF2 em `config.json`; "Ativar status de
   fila"; lotação publicada; zerar; cofre da chave de publicação.

Estado vivo em `fila.json` (branch `fila`), escrito pela API do GitHub e lido por raw.githubusercontent.com.

Depois: criar no GitHub um **fine-grained PAT** (Resource owner hamadmkalaf → só `dublineleicoesfinal` →
Repository permissions → Contents: Read and write), abrir `…/v3/admin/`, entrar com a senha do admin,
colar a chave em "Guardar chave", marcar "Ativar status de fila" e "Gravar". Na equipe, a chave é
colada uma vez por aparelho, na primeira publicação (fica cifrada com a senha do dia).
